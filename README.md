# Substation-Secondary-Guard（变配电二次侧“治未病”智能诊断助手）
> 立足电气自动化二次运维痛点，结合边缘侧确定性计算与大模型推理，实现基层供电所低成本、防泄密、零编程快速部署的潜伏期隐患预警。
## 核心安全红线
- **端云隔离与数据脱敏**：本地 CPU 运行 `edge_analyzer.py` 对传感器时序数据做确定性阈值与斜率统计，仅输出去标识化的物理特征摘要。
- **越权控制熔断**：严格遵循电力二次系统安全防护规定，本 Agent 仅运行于管理信息大区，严禁下发任何遥控分合闸指令，仅生成标准化人工消缺建议单。
- **零编程快速复制**：不同供电所仅需修改 `electrical_rules.md` 中的定值与规程参数，即可快速完成同类配电室的智能化改造。
